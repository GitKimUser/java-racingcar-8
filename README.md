### ## 🚀 기능 목록

- [x] **자동차 이름 입력 기능**
  - [x] 경주할 자동차 이름을 쉼표(,)를 기준으로 구분하여 입력받는다.
- [ ] **자동차 이름 유효성 검사 기능** (← △를 [ ]로 변경)
  - [x] 각 이름이 5자 이하인지 검증한다. (초과 시 예외 발생)
  - [x] 이름에 공백 또는 빈 문자열이 있는지 검증한다. (존재 시 예외 발생)
  - [ ] 중복된 이름이 있는지 검증한다. (존재 시 예외 발생)
- [x] **시도할 횟수 입력 기능**
  - [x] 시도할 횟수를 입력받는다.
- [ ] **시도할 횟수 유효성 검사 기능**
  - [ ] 입력값이 숫자인지 검증한다. (아닐 시 예외 발생)
  - [ ] 입력값이 1 이상인지 검증한다. (아닐 시 예외 발생)
- [x] **자동차 객체 생성 및 경주 준비 기능**
  - [x] 입력된 이름들을 바탕으로 Car 객체를 생성한다.
  - [x] 생성된 Car 객체들을 리스트로 관리한다.
- [x] **경주 진행 기능**
  - [x] 각 자동차별로 무작위 값을 생성한다.
  - [x] 무작위 값이 4 이상일 경우 자동차를 전진시킨다.
  - [x] 주어진 시도 횟수만큼 위 과정을 반복한다.
- [ ] **실행 결과 출력 기능** (← △를 [ ]로 변경)
  - [ ] 각 차수별로 자동차의 이름과 현재 위치를 출력한다. (`pobi : --`)
- [ ] **최종 우승자 결정 및 출력 기능**
  - [ ] 가장 많이 전진한 자동차를 찾는다.
  - [ ] 최종 우승자를 형식에 맞게 출력한다. (단독/공동 우승자 구분)
